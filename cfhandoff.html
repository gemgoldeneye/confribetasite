# ConvoyFriends — Project Handoff

You are picking up an in-progress design/build project. Here is everything you need.

## 1. Product

ConvoyFriends is a mobile app (iOS + Android) that keeps groups of friends connected on road trips. Core features: live convoy map, in-trip voice chat, smart re-routing when someone falls behind, synchronized pit stops, and group ETA.

- Tagline: "Drive together, navigate smarter."
- Public site: https://convoyfriends.app/
- Stage: Pre-launch, beta program now open. Cap of 300 founding drivers.
- Audience: Road-trippers, motorcycle riders, supercar owner groups, overlanders, RV/bus tour drivers.

## 2. Brand System

Colors:
- Night ground: #050B16
- Navy surface: #0A1628
- Cyan accent: #3DD9F5
- Teal accent: #2BC4A8
- Brand gradient: linear-gradient(92deg, #3DD9F5 0%, #34D2C7 48%, #2BC4A8 100%)
- Ink (white): #F5F8FF
- Muted ink: #9AA8C2

Typography:
- Display: Sora, weights 700/800, letter-spacing -0.025em (headlines, UI labels)
- Body: Inter, weights 400/500, line-height 1.55–1.7
- Mono: JetBrains Mono (IDs, codes)

Voice: confident, road-trip-coded, friendly but not chummy.

## 3. Beta Landing Page (already built)

Single file: index.html. Sections in order:
1. Hero — gradient headline "Drive Together, Navigate Smarter.", supporting copy, primary CTA, animated SVG phone mock with a live convoy map.
2. Benefits — two cards:
   - "Enjoy the early version of ConvoyFriends"
   - "Be Part of the VIP Group"
3. Application form — full-width card with a top progress bar, inline validation, and a success state that issues a CF-XXXXXX application ID.
4. How it works — 4-step timeline: Apply → Get matched → Install build → Hit the road.
5. Footer — links to convoyfriends.app, privacy, terms, contact.

## 4. Beta Application Form Schema (all fields required)

- name (text) — Full Name
- location (text) — City, Region/Country
- email (email) — validated
- phone (tel) — minimum 7 digits
- device (radio: iPhone | Android) — segmented control
- vehicle (radio: Motor | Car | Supercar | Truck | Bus) — pill grid with custom icons
- dream (textarea) — "If you had a weekend convoy trip, where would you go and how many friends?"

Submit triggers a success state showing the user's first name and a generated reference code in the format CF- followed by 6 digits.

## 5. Likely Next Tasks

- Wire form submission to a real backend (Formspree, Airtable, or custom endpoint).
- Compose acceptance + waitlist email templates.
- Build the founder VIP Discord onboarding flow.
- Localize copy for Tagalog and Spanish markets.
- Replace SVG phone mock with a real product screenshot once the build is stable.

## 6. How to help

When I ask for changes:
- Stay inside the brand system above. Do not invent new colors or fonts.
- Use the cyan→teal gradient for accents only — never on large surfaces.
- Keep the dark navy background; the brand is night-mode native.
- Match the existing component vocabulary (rounded radii 12–24px, soft inner highlights, glass-card translucency on the navy surface).
- Ask before adding new content sections; do not pad with filler.
